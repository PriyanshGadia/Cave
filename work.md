## 12. SCROLL ENGINE

---

The scroll engine must be reliable.

Do not hijack the wheel.

Do not call preventDefault() on normal wheel events.

Do not create a fake scrollbar.

Do not rely on a virtual scrolling library.

Use native document scrolling.

Read scroll position.

Convert it to normalized page progress.

Interpolate animation state with requestAnimationFrame.

Recommended model:

scrollProgress = scrollY / maxScroll

sceneProgress = scrollProgress \* sceneCount

activeScene = floor(sceneProgress)

localProgress = sceneProgress - activeScene

Clamp all values.

Use smooth interpolation for visuals.

DO NOT interpolate actual document scrolling.

Only interpolate the scene's visual response.

This preserves normal:

mouse wheel
trackpad
touch scroll
keyboard scrolling
Page Down
Page Up
Home
End

behavior.
