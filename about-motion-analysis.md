### 1. Executive Summary & Thesis
The goal is **not** "an About page with cool animations," but:
> **"A premium personal portfolio that happens to behave like a cinematic interactive experience."**

```
PERSONAL IDENTITY (Priyansh Gadia: Engineer, Builder, Systems Architect, Deep-Tech Creator)
```

### 2. Deconstructed Reference Grammar

#### Reference A: Editorial Graphic / Ink Novel Language (Sonochi Spirits / Notturno)
- **Viewport Dominance**: 80–90% visual art. Typography is large, bold, architectural (10–15%). Interface is minimal and floating (5%).
- **Color Grammar**:
  - Deep Obsidian Black (`#05060a`)
  - Warm Paper / Off-White (`#f2efe9`)
  - Deep Architectural Crimson (`#8b1e28` / `#b31b2c`)
  - Cold Precision Titanium (`#1e2430` / `#94a3b8`)
  - Sensor Indicator Accents (restrained cyan `#00f2ff`, warm amber `#f59e0b`)
- **Transition Grammar**:
  - The *artwork itself* conducts the transition.
  - Graphic ink-edge wipes and vertical line-raster frequency shifts (as seen at 08s in the reference video).
  - Foreground structural elements wipe the camera as it dollies laterally.
  - Crimson circular focal stamps that expand to become spatial portals or focal apertures.

#### Reference B: Product & Subject-Centric Motion
- **Subject in Motion**: We never animate flat cards around a static backdrop. We animate the *subject*—the camera pulls into the desk, glides across the hand-sketched transformer schematics, orbits the Argus edge-vision rack, and penetrates the borosilicate cooling chamber.
- **Continuous 2.5D Depth**:
  - Background (Basalt cavern columns & geological strata)
  - Midground Architecture (Structural steel gantry, cable trays, workstations)
  - Subject (Priyansh actively engineering, coding, testing, calibrating)
  - Foreground Artifact (Real project schematic, breadboard, oscilloscope, telemetry monitor)
  - Overlay Typography (Integrated into spatial planes, moving with slight parallax)

#### Reference C: Project as Artifact Experience
- Instead of a generic 3-column web card grid:
  ```
  WORKBENCH ARTIFACT → CAMERA APPROACH → FOCAL ISOLATION → SPEC & SOURCE CODE → NEXT TRAJECTORY
  ```
- Each project has a physical anchor in the workshop:
  1. **Cave / VAULT-01**: Central holographic console / real-time procedural WebGL engine.
  2. **Argus**: Articulated dual-rack vision cluster & telemetry system.
  3. **Respiratory Support Optimization**: Biomedical clinical workstation & MIMIC-IV waveform monitor.
  4. **CryptoGraph Analytics**: High-frequency orderbook ticker & spatio-temporal GCN flow display.
  5. **IDP Engine / LLM Systems**: Multi-layer layout extraction station with real-time tokenizer stream.

#### Reference D: Master Camera Choreography & Scroll Physics
- **Master Time Variable**: Single normalized timeline `progress ∈ [0, 1]`.
- **Bidirectional Fidelity**: Scrolling forward advances the camera smoothly; scrolling backward reverses every matrix transform, wipe, and opacity interpolation without state corruption.
- **Reduced Motion Support**: When `prefers-reduced-motion: reduce` is detected or toggled, the page gracefully transforms into a clean, editorial horizontal/vertical portfolio where all imagery, project descriptions, GitHub links, and contact channels remain instantly accessible.

### 4. Transition Mechanism Catalog
1. **Vertical Ink / Raster Frequency Distortion**: High-frequency scanline phase modulation mimicking the reference video.
2. **Foreground Geometric Wipe**: Steel structural pillars and robotic armature pass across the lens as the camera pans.
3. **Focal Crimson Aperture**: Expanding circular graphic ring revealing the next focal plane.
4. **Conduit Energy Pulse**: High-speed luminescence streak traveling down floor umbilical cables into the next terminal.
5. **Continuous Camera Dolly**: Smooth Z-axis push-through that travels into a display screen or drafting sheet to emerge in the next sector.
